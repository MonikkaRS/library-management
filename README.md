# Library Management

A responsive library dashboard built with HTML and CSS. It includes a summary of library activity, a book collection table, and a form layout for adding books.

## Files

- `index.html` — page structure and sample book data
- `styles.css` — layout, colors, and responsive styles

## Getting started

1. Create a folder for the project.
2. Save the HTML code as `index.html`.
3. Save the CSS code as `styles.css` in the same folder.
4. Open `index.html` in a web browser.

## Features

- Library statistics cards
- Book collection table with sample records
- Book search field design
- Add-book form design
- Responsive layout for smaller screens

## Note

This is a front-end HTML and CSS template. The search field and add-book form are visual only; they do not store or update book records without JavaScript and a backend.
